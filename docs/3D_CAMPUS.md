# Three 3D dioramas

All three environments now open as stylized 3D dioramas: 18-room Orpheus Campus, 15-room Meridian Observatory and 17-room Saltwind Terminal. The fixed orthographic camera, low-poly witnesses, muted coral/sage coats, painted room lettering, paper labels and ink edges extend the existing visual identity. Lab benches, racks, archive shelves, plants, fixtures and distinct physical records are authored geometry, not downloaded model packs. The observatory has telescopes, chart tables, signal consoles and generator machinery. The terminal has cargo, navigation consoles, galley counters and lifeboats. Seven new rooms contain independent physical records rather than empty floor space.

Every map selects 3D. The old manual 2D setting has been removed and saved legacy preferences are ignored. Graphics initialization or context failure automatically falls back to an illustrated view with the same physical layout and a visible status message. The fallback uses the same furniture manifest for all maps.

The server's two-dimensional coordinates become the 3D floor plane. Camera-relative controls rotate the input vector without changing its magnitude. The existing acceleration, local prediction, remote interpolation, authoritative collisions, line-of-sight visibility, interaction radius and authenticated messages remain in use. Reveal camera framing follows only the completed incident's public result; it never reads private memories. Evidence inspection thumbnails are rendered once from the same meshes using the existing context and cached by object kind.

Performance choices:

- Static campus geometry is batched into three instanced shape draws, one combined ink-edge draw and one room-label atlas draw. Geometry and materials are built once per scene.
- Rigid character parts sharing a material are merged while legs/head retain small skeletal-free animations. Character meshes remain batched by material; extended headwear adds only a small accessory batch. Witness meshes use actual depth testing and frustum culling. The old binary line-of-sight toggle is removed: low cutaway walls no longer make whole people vanish. Inspection still requires physical line of sight.
- There are no shadow maps, postprocessing passes, downloaded textures, physical simulation, extra movement dimensions or additional game socket messages. Lighting uses one hemisphere and one directional light, with painted fixtures and simple contact-shadow discs.
- Active rendering follows the display refresh clock instead of dropping 16.5 ms frames at a nominal 60 Hz gate. Movement remains time-based. Backing density is capped at 1.5; sustained slow frames lower resolution, and sustained smooth frames restore it with hysteresis. Hidden tabs stop rendering. The mostly static results background renders four times per second.
- Resize dimensions stay positive, including temporary zero-sized containers. Leaving, rematching or losing a context removes input/network listeners and disposes mesh geometry, materials, textures, instancing buffers and the renderer context.
- Both renderers are lazy chunks. Entering the campus loads the 3D chunk; the larger Phaser chunk loads only for graphics failure. The title/lobby load neither engine.

Wardrobe, lobby and results use 96 cached WebP portraits rendered from `WitnessModel`, avoiding per-card contexts or animation loops. Rebuild with `scripts/render_witnesses.mjs <path-to-sharp>`.

Headphones now have a continuous curved band, padded round earcups and coat-colored outer trim. Walking turns ease toward movement velocity; walk cycles blend in/out. Delayed position corrections have bounded speed while walking, preventing a late packet from visibly pulling a steadily moving character backwards.

Verification includes geometry/draw budgets, camera-relative controls, positive framebuffer bounds, local prediction, wall visibility, reconnect reset, removed-player disposal, hidden-tab pause, context failure, adaptive resolution, thumbnail creation, legacy preference removal and fallback. These tests complement browser evidence and real multiplayer cases; they do not establish compatibility with every GPU or browser.

`backend/app/layout.py` supplies one public manifest for 3D art, client prediction, server collision and scripted navigation. Benches, racks, shelves, plants and raised evidence props are solid; paper, glass fragments and footprints remain on the floor. Furniture keeps door approaches open. The CCTV console has moved back from its doorway. Connecting an older saved room moves any witness embedded in new scenery to a nearby walkable spot without changing the incident. Open sliding-hatch pockets and thresholds mark actual openings. Retracted panels stay outside the walkable gap; the floating overhead beam has been removed. The incident reveal retains the established sequence panel; this revision changes its underlying campus presentation and camera framing, rather than adding a new historical movement simulation.
